Increasingly popular and widely used, **Apache Hive** is a data warehouse system for **Hadoop**. **Hive** enables data summarization, querying, and analysis. **Hive** queries are written in **HiveQL**, a query language similar to SQL. **Hive** lets you project structure onto large volumes of unstructured data.

Once you've defined the structure, you can use **HiveQL** to query the data without any knowledge of Java or **MapReduce**.
